# Google Play content rating (IARC questionnaire): I Want India

Email for IARC certificate: the support email from `legal/config.json`.

**Category:** "All Other App Types" / "Utility, Productivity, Communication, or Other" (a local services and shopping marketplace with buyer-seller chat). It is not a game, not a social network and does not stream media.

| Question | Answer | Why |
|---|---|---|
| Violence (any depiction) | No | Marketplace content only; violent content is prohibited by the Community Guidelines and moderated |
| Fear / horror | No | |
| Sexuality, nudity, sexual references | No | Prohibited content; image uploads screened with Cloud Vision SafeSearch |
| Language (profanity, crude humour) | No | No editorial content with profanity; UGC is moderated |
| Controlled substances (drugs, alcohol, tobacco) | No | Alcohol, tobacco, vapes, medicines and drugs are blocked categories |
| Gambling / simulated gambling | No | Gambling and lotteries are prohibited |
| Does the app allow users to interact or exchange content with other users? | **Yes** | Buyer-seller chat, requests, quotes, photos and reviews. Report, block and moderation in place |
| Does the app share the user's current physical location with other users? | **No** | Only the locality / postal code of a request is shown; the exact address the user typed is shared only with the seller they accept, not live GPS |
| Does the app allow users to purchase digital goods? | **Yes** | Seller subscriptions and quote-credit packs (Play Billing) |
| Does the app contain unrestricted internet access (a web browser or search engine)? | **No** | Links open in the system browser |
| Does the app promote or depict any of the above in ads? | No | No ads |
| Is the app a news app / contains news content? | No | |

**Expected result** (confirm on the certificate): ESRB Everyone, PEGI 3, USK 0, ClassInd L, IARC Generic 3+, with interactive elements **"Users Interact"** and **"In-App Purchases" / "Digital Purchases"**. The target audience is still set to 18+ (see `play-app-content.md`); a low content rating does not change that.
