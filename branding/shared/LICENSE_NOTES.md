# Licence notes (branding)

- **"I Want" mark** (`mark.svg`, speech bubble + upward arrow): original placeholder geometry drawn in
  `tool/branding/generate.py`. Owned by the project; no third-party artwork, icons or stock imagery are used.
- **Fonts:** Inter and Noto Sans Devanagari, SIL OFL 1.1 (see `fonts/README.md`). Placeholder PNGs are rasterised with
  locally installed DejaVu Sans (Bitstream Vera licence / public-domain changes) and GNU FreeSans (GPLv3 with font
  exception), which permits use in rendered images.
- **Colours:** Tailwind CSS "slate" neutrals (MIT) and Material 3 error tones (Apache 2.0) used as values only.
- Store / social sizes in `sizes.json` are facts taken from each platform's public help pages (linked per entry).
- Before launch: run a trademark search for "I Want USA" / "I Want India" in the USPTO and Indian TM registry and
  confirm the final logo does not resemble existing marks.
